# 3D Head and Other Angles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn a sketch version into an approximate 3D head, rotate it in the browser, save chosen angles as pencil sketches, print them on the case sheet.

**Architecture:** A separate GPU worker (`head3d/`, FastAPI + PyTorch + TripoSR) turns a photo PNG into a GLB. The backend calls it over HTTP through an injectable client, stores heads and angle views, and redraws browser-captured renders with the existing image model. The frontend shows the GLB with three.js.

**Tech Stack:** FastAPI, SQLModel, httpx, PyTorch + TripoSR (worker only), trimesh, three.js.

**Spec:** `docs/superpowers/specs/2026-10-28-3d-head-design.md`

## Global Constraints

- The app environment never imports torch; only `head3d/` does.
- `HEAD3D_URL` empty → routes return 503 `HEAD3D_OFF`, `/health` reports `"head3d": "off"`, the panel is hidden.
- Every 3D-derived image is labelled "approximate" in UI and on the sheet.
- Case routes use `require_case_access`; another case's head/view → 404.
- Audit actions `head_create`, `angle_view_create` in backend and `frontend/src/types.ts:AUDIT_ACTIONS`.
- Prompts free of `suspect`, `criminal`, `mugshot`, `police`.
- One commit per task, pushed to `origin main`; no Claude co-author trailer.

## Review Focus

- Render upload that is not a PNG, or over 4 MB → 422 before any AI call.
- Worker down or slow → 503 `AI_UNAVAILABLE`, audited, nothing stored.
- Version without a realistic photo → photo made first, then the head.
- A head of case A requested under case B → 404.
- Feature off → panel hidden and routes 503, rest of the app unaffected.

**Interfaces:**
- `class Head3DClient(Protocol): def make_head(self, photo_png: bytes) -> bytes` (GLB). `HttpHead3DClient(url)` posts `image/png` to `{url}/head`, timeout 180 s; any httpx error or non-200 → `AppError("AI_UNAVAILABLE", "The 3D service did not respond. Try again.", 503)`.
- `app.state.head3d_client: Head3DClient | None` (None when `head3d_url` is empty).

- Worker: `POST /head` (raw PNG body) → GLB; `GET /health` → `{"status": "ok"}`.
